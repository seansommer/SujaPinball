# Original Pinball audio masters

- `factory.mp3`: Fresh Pressed Groove, instrumental funk/electro table music.
- `rainbow.mp3`: Rainbow Rush, the faster multiball theme.
- `bottle-ready.mp3`, `fresh-bottle.mp3`, `rainbow-rush.mp3`,
  `extra-ball.mp3`, `game-over.mp3`: custom juice-factory cabinet callouts.

These original recordings were created specifically for SUJA Pinball through
Runway on October 19, 2026. Music briefs called for a tactile, joyful funk
groove with clavinet, bass, brass, marimba, and liquid synth accents, leaving
room for mechanical gameplay sounds. Callouts use the Xylar preset voice.

Runtime music is cropped, level-balanced, and joined with a two-second
crossfade so a loop returns smoothly to its beginning. The full masters are
retained here. Runtime callouts are level-balanced separately. Jackpot uses
an original synthesized musical celebration.

Future media: use the native ChatGPT image generator for all images. Discuss
direct ElevenLabs access before new paid audio work. Runway generation requires
explicit user approval each time; do not use it as an automatic audio provider.
