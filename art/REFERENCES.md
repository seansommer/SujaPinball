# Pinball cabinet design references

These primary sources informed the design review. No table artwork, sounds,
ROMs, or source code were copied from them.

- Mission Pinball Framework: event-driven devices, scoring, light shows,
  ball saves, multiballs, and mode progression.
  https://missionpinball.org/latest/
- Pinball Schminball: separate table actors and renderers; shot devices
  and event triggers in a browser pinball game.
  https://github.com/igorski/pinball-schminball
- VPX-JS: a reference for the scope of a complete browser pinball simulation.
  https://github.com/vpdb/vpx-js

SUJA's cabinet remains original: live fruit bumpers, a filling/capping bottle,
chrome conveyor, juice spinner, pressure-driven double scoring, linked-shot
bonuses, and one physical outlane kickback per ball. The runtime score schema
stays compatible with the existing shared rules.
